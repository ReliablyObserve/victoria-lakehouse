- **The traces binary's Jaeger and Tempo routes now run under VictoriaTraces' query deadline (#778).** Trace-by-ID, search, services, operations, dependencies, Tempo search and TraceQL, tag and tag-value lookups and TraceQL metrics ran with no deadline, so a stalled S3 read or consumer held the query, and the file-budget slot it had taken, until the client went away. They now run under `-search.maxQueryDuration` (upstream's flag, name, default 30s and help text; a request may lower it with `timeout=`, never raise it) and answer a deadline as a hot VictoriaTraces node does. This is a new default for these routes (unlimited before, 30s now); raise the flag for longer queries. The LogsQL routes keep `query.timeout`; the logs binary is unchanged.
