- **The pull request quality report is computed in CI as an artifact (tooling only, no change to the Lakehouse binaries or to runtime behaviour).** The informational `pr-quality` workflow measures what a product pull request changes (`go test -cover` and `golangci-lint --new-from-rev` on the changed packages against the merge base, the test, fuzz-target and registry counts, the parity allowlist and the flaky-test watch) and uploads `manifest.json`, `quality.json` and the rendered comment body as the artifact `pr-quality`; the two JSON schemas are in `scripts/bench/ab/schemas/` and the format is documented in `docs/pr-perf-smoke.md`. It has no write permission; posting is a separate `workflow_run` job.
