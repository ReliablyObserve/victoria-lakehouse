- **The pull request quality report is computed in CI as an artifact for the proof commenter (tooling only, no change to the Lakehouse binaries or to runtime behaviour).** The informational `PR Quality` workflow measures what a pull request changes (`go test -cover` and `golangci-lint --new-from-rev` on the changed packages against the merge base, the test, fuzz-target and registry counts, the parity allowlist and the flaky-test watch) and uploads the commenter's artifact `lh-proof-comment` (`manifest.json` and the already rendered, escaped `pr-quality.md`, also when the job failed or has nothing to report) and `pr-quality-data` (`quality.json`, schema in `scripts/bench/ab/schemas/`); the format is documented in `docs/pr-perf-smoke.md`. It has no write permission.
